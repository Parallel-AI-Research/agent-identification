Each product page now has a **Status** section that shows whether your install is working.

## What's new

- **Waiting or receiving:** a product shows **Waiting for installation** until the widget actually loads on one of your origins. It then shows **Receiving events**, with where it loaded and when. Copying the snippet never changes it.
- **Declarations:** Status shows when the last declaration arrived.
- **Refusals you can fix:** if a page on an unlisted origin tries to load the widget, or a server uses a secret the collector doesn't accept, Status says so and explains the fix. Refusals clear once fixed, or after a week.
- **Your products list** shows each product's status at a glance.

---
title: Declaration widget
description: An optional prompt that asks visitors whether they're an AI assistant or a person. Every visitor sees it.
---

<Callout type="warn">
  Every visitor sees this widget, people included. It isn't part of the default install, which draws
  nothing on your pages. Only add it where you're happy for everyone to see it.
</Callout>

The widget asks each visitor how they're visiting: **AI assistant**, **Person** or **Prefer not to say**. It records what they choose. An answer is self-reported, so it never proves who a visitor is.

Your product page has these snippets under **Optional: the declaration widget**, with your own site ID filled in. They're for pages that already have the [page script](/docs/install#the-page-script): the widget joins the tab's session, so an answer sits next to that visit's page views, and the snippets turn the widget's own page views off so a visit isn't counted twice. Without the page script, leave page views on.

## Script tag

```html
<div id="visitor-choice"></div>
<script
  defer
  src="https://parallel-agent-identification.vercel.app/sdk/v0.6.0/agent-id.js"
  data-site="YOUR-SITE-ID"
  data-target="#visitor-choice"
  data-mode="optional"
  data-page-views="off"
></script>
```

Without `data-target`, the widget adds itself to the end of the page.

## JavaScript

```sh
npm install https://parallel-agent-identification.vercel.app/downloads/parallel-research-agent-identification-0.6.0.tgz
```

```js
import { init } from "@parallel-research/agent-identification";

const widget = init({
  container: "#visitor-choice",
  siteId: "YOUR-SITE-ID",
  apiUrl: "https://parallel-agent-identification.vercel.app",
  mode: "optional",
  // The page script records page views.
  pageViews: false,
});
await widget.ready;
```

## React and Next.js

React is an optional peer dependency. In Next.js, render this from a client component:

```tsx
"use client";
import { AgentIdentification } from "@parallel-research/agent-identification/react";

export function VisitorChoice() {
  return (
    <AgentIdentification
      siteId="YOUR-SITE-ID"
      apiUrl="https://parallel-agent-identification.vercel.app"
      mode="optional"
      pageViews={false}
    />
  );
}
```

## Optional and required modes

| Mode       | What the visitor sees                                               |
| ---------- | ------------------------------------------------------------------- |
| `optional` | The prompt, which they can ignore.                                  |
| `required` | The prompt, which must be answered before using a section you gate. |

To gate a section, add `data-mode="required"` and `data-gate="#your-section"`. Any of the three answers unlocks it, and it only unlocks once the collector has accepted the answer.

A gate in the browser can be bypassed, so it doesn't protect anything by itself. Use [server verification](/docs/server-verification) for protected actions.

## Check it works

Load a page on one of your origins. **Status** on your product page says when your pages on that origin last reported. Answer the prompt, and it should say **Response recorded**. Status then shows when the last declaration arrived.

The widget only works on the origins you list. A page on another origin is refused, and Status says which one.

## Content Security Policy

If your site uses one, allow the collector in `script-src`, `style-src` and `connect-src`. The widget needs no inline scripts or styles.

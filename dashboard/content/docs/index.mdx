Agent analytics helps you understand how AI agents use your product. Your server tells the collector about the requests it already receives, and your dashboard shows which agents came and what they did. Nothing is added to your pages, so your visitors see nothing, and agent builders install nothing.

## What you get today

- **Signed agents, verified.** Some agents sign their requests with [Web Bot Auth](/docs/signed-agents). The collector checks each signature against the keys its operator publishes, so a verified visit names the company running the agent.
- **Automation signals.** A request whose user agent names an AI agent, such as `ChatGPT-User` or `ClaudeBot`, or a headless browser, is recorded as [suspected automation](/docs/activity#automation-signals).
- **Actions.** Your server can report what visitors did, such as an order placed or a message sent, and whether it succeeded.
- **A dashboard** for your products, environments, origins, domains and secrets, with an [Activity](/docs/activity) page for each environment.

There's also an optional [declaration widget](/docs/declaration-widget) that asks visitors whether they're an AI assistant or a person. Every visitor sees it, people included, so it isn't part of the default install.

## Evidence, not proof

A verified signature identifies an agent's operator, never the person or account it acts for. A user agent is only a claim, because anyone can send one. An agent that neither signs nor names itself stays unknown, and unknown never means human. Read [what it can't do](/docs/limits) before you rely on it.

Agent analytics helps you understand how AI agents use your product. It starts with a visible prompt on your site, which asks each visitor how they're visiting:

- **AI assistant**
- **Person**
- **Prefer not to say**

You install it on your own site. Visitors and agent builders install nothing.

## What you get today

- A prompt you can add with a script tag, a package or a React component.
- A record of each answer, kept separately for each product.
- Optional server checks that tie an answer to your own signed-in session.
- A dashboard to manage your products, origins, domains and secrets.

Activity tracking and analytics views are still being built. See the [changelog](/changelog) for what's shipped.

## An answer is not proof

Every answer is self-reported. A visitor can skip an optional prompt or give a different answer, so this doesn't detect every agent or prove who a visitor is. Read [what it can't do](/docs/limits) before you rely on it.

Your coding agent can do the install for you. In the dashboard, open your product and choose **Set this up with your coding agent**, then paste the instructions into your agent.

The instructions are generated for your product. They include your site ID, the collector and your allowed origins. They hold no secrets, so they're safe to share with any tool.

## What the agent does

1. Finds where your server handles requests: middleware, a request hook, or Next.js's `proxy.ts`.
2. Adds the two reporting calls there, without changing how any request is handled.
3. Adds the [page script](/docs/install#the-page-script) to your shared layout or template, so every page has it.
4. Asks you to set `AGENT_ID_SITE_SECRET` yourself.
5. Opens a page, requests one as a headless browser, and asks you to check that **Status** says **Receiving events**.
6. Tells you which files it changed and what it checked.

The instructions tell it to add only the page script to your pages, and not the [declaration widget](/docs/declaration-widget), because every visitor would see the widget.

## What to check yourself

- **Nothing changed on your pages.** Visitors shouldn't see anything new. The only addition is the page script's tag.
- **Your server secret isn't in the code.** It should only ever come from an environment variable that you set.
- **The reports don't hold up your responses.** Both calls run in the background.

## Docs for agents

These docs are also published in plain text, so your agent can read them directly:

- [`/llms.txt`](/llms.txt) lists every page.
- [`/llms-full.txt`](/llms-full.txt) has all the docs in one file.
- Add `.md` to any docs address for that page in Markdown, such as [`/docs/quickstart.md`](/docs/quickstart.md).
